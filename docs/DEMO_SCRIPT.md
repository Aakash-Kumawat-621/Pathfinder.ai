# 3–5 minute demo script

## 0:00–0:35 — The problem
“Learning platforms give learners a huge list of resources, but not the right sequence. PathFinder converts a goal into a prerequisite-safe, personalized roadmap.”

## 0:35–1:20 — Conversational profiling
Enter:
> I want to become a data scientist. I know basic Python and I’m new to machine learning.

For the background question, enter:
> Python; completed py101

For time:
> 5–10 hours a week

Point out that the profile now contains target domain, level, known skills, prior course completion and study pace.

## 1:20–2:15 — Explainable path
Show the Learning Path. Highlight:
- real catalog resources rather than hallucinated course names;
- prerequisite ordering;
- milestone grouping;
- estimated total workload;
- “Why this is here” explanation;
- optional semantic recommendations.

Open “Explainable AI pipeline” to show Profiler → semantic retrieval → graph ranking → Advisor → validation.

## 2:15–2:55 — Adaptation
Mark one item **Completed**. Then give another item a **👎**.

Say:
> “The feedback changes ranking, but the graph constraint still prevents an item from moving ahead of its prerequisite.”

## 2:55–3:40 — Intelligence dashboard
Show:
- overall progress;
- skill coverage;
- role-readiness radar;
- biggest skill gap;
- next best action;
- badges.

## 3:40–4:20 — AI advisor
Ask:
> Why do I need statistics before machine learning?

The advisor is grounded in the current learner profile/path rather than inventing a new curriculum.

## Closing
“PathFinder combines AI for understanding and explanation with deterministic graph algorithms for safety, giving us personalization without sacrificing reliability.”
